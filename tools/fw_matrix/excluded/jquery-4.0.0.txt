# jQuery 4.0.0 (tag 4.0.0, 4f2fae08f23b): the tests Crane's matrix does not run, each with its reason
# (tools/fw_matrix/exclusions.zig documents the format; tmp/plans/framework-matrix-plan.md section 3 the rule).
# Ids are QUnit full names, "<module>: <test name>", as QUnit's filter matches them.
# Every entry was checked by hand against the test's source at the tag.

# Since fw1 b4 (2026-11-14) every test runs but these: the pages are served by jQuery's own test server
# (jquery-test-runner's `jtr serve -m test/middleware-mockserver.cjs`, under Node 24.22.3), so the 118 tests that
# needed its mock actions run, and its `babel:tests` step writes the one transpiled file a test page loads. Of
# them, "support: Check CSP ... restrictions" moved here: it compares the same layout-measured support values as
# its three support siblings below (jQuery.extend drops their undefined values: src/core.js "Don't bring in
# undefined values").

# ---------------------------------------------------------------------------------------------------------------
# EXCLUDED: rendering (ruling R7). A test is here when an assertion's expected value needs a layout box or pixels:
# :visible/:hidden (offsetWidth || offsetHeight || getClientRects().length), offset*/client*/scroll* geometry,
# .offset()/.position()/.offsetParent(), the window's and the document's sizes, and resolved values that CSSOM
# defines as used values (auto/%/content-based sizes as px). Read by hand at the tag from the diagnosis run of
# 2026-11-11 (lane fw1, unfiltered). NOT excluded, though they read sizes: jQuery's dimension getters over sizes the
# element declares in px (width/inner/outer arithmetic from computed padding/border/box-sizing is the style system:
# dimensions "width(Function(args))", "height(Function(args))", "fractional getters", both "child of a hidden
# elem" tests, "hidden element with dimensions from a stylesheet", the three SVG tests, "passing undefined is a
# setter", "width/height on element with transform"; basic "dimensions"; effects "animate block width/height",
# "Animations with 0 duration don't ease", "slideDown() after stop()"), and offset tests that assert only the shape
# of the result or a box that cannot exist ("empty set", "disconnected element", "hidden (display: none) element",
# "normal element", "chaining").
# ---------------------------------------------------------------------------------------------------------------
