# Where each generation was swept: the host every results run of main ran on,
# that host's OS and architecture, and how many WPT runners the run used. Read
# by tools/wpt_site/ (the public results site): a generation's entry and its
# history row name the host of the generation's largest run - its sweep - as
# the progress history records it (progress-history.json, `sources`).
#
# The integrator appends one line when a sweep lands in wpt-results/<label>/,
# before regenerating. A line is keyed by the run's LABEL, not by a generation
# number: the label is known the moment the run is copied in, while the number
# is only assigned by wpt-progress, and only when results moved. A line written
# for "the next generation" would attach to whichever run became it. The
# sweep's own journals record no host, OS or runner count, and wpt-results/ is
# not committed. So this committed file is the record (lane site1, 2026-11-09).
#
# Format: one run per line, four or five fields separated by spaces:
#
#   <label>  <host>  <os>-<arch>  <runners>  [fonts=<hash>]
#
#   label    the run's directory under wpt-results/ (sweep-<sha>), listed once
#   host     the pool host's name as crane-pool.sh prints it (chat.local, server1)
#   os-arch  linux-<arch> or macos-<arch> (linux-x86_64, macos-arm64)
#   runners  the runner count the sweep used, a whole number above 0
#   fonts    the host's font set when it swept: the first 16 hex digits of the
#            sha256 of its `fc-list : family style file` output, sorted (Linux)
#            or of `system_profiler SPFontsDataType` (macOS), which gen-sweep.sh
#            writes beside the sweep as fonts.txt. The production run (wpt_runner,
#            from its first generation on) takes its fonts from the host as a browser
#            does, so a generation names the set its results came from (lane
#            wptcfg; wpt.fyi pins its runners' fonts in their image). Optional.
#
# Blank lines and lines starting with # are ignored. An invalid line stops the
# site with its line number. A run that is not listed shows as "not recorded".
#
