Status of this document

Crane is a web platform engine written in Zig: the browser, minus the pixels. This is its record of its own results on the web-platform-tests (WPT), measured by its own runner and regenerated with every run. Scope: the 10,035 testharness files of the 0.1 worklist, in 46 suites. Reftests and tests that need rendering or layout (html/rendering/, canvas, scrolling, focus traversal) are out of scope by design, and every total describes this scope and nothing wider.

About the totals. Crane passes 1,429,799 of the 1,635,301 subtests its runs reported. This is not a browser comparison, and the subtest total mostly measures encoding/, which holds 70% of all reported subtests (1,151,711 of 1,635,301) in 152 files. A file blocks the 0.1 gate when it times out, errors, crashes or finishes with no subtest passing (TIMEOUT, ERROR, CRASH, NONE-PASSED): 3,789 files block today. Per-subtest detail comes from the runner’s result streams: no file has it in this generation yet, so each file’s page gives its counts.

How to read a section

Each suite is a numbered section that opens with its own subtest numbers. Its Conformance box counts files by standing; its Tests tables link to a page for every directory and every test file, and a test file’s page lists its subtests. Everything has a permanent link, ¶.
