Status of this document

Crane is a web platform engine written in Zig: the browser, minus the pixels. This is its record of its own results on the web-platform-tests (WPT), measured by its own runner and regenerated with every run. Scope: the 13,141 testharness files of the 0.1 worklist, in 54 suites. Reftests and tests that need rendering or layout (html/rendering/, canvas, scrolling, focus traversal) are out of scope by design, and every total describes this scope and nothing wider.

About the totals. Crane passes 1,891,766 of the 1,902,237 subtests its runs reported. Chrome’s results on the same files are in Crane and Chrome, beside Crane’s and never counted in them, and the subtest total mostly measures encoding/, which holds 61% of all reported subtests (1,152,343 of 1,902,237) in 152 files. A file blocks the 0.1 gate when it times out, errors, crashes or finishes with no subtest passing (TIMEOUT, ERROR, CRASH, NONE-PASSED): 288 files block today. Not counted among them: 1 file that would block is exempt until an upstream test bug is fixed: Chrome, Firefox and Safari fail it identically because of a bug in the test, filed with web-platform-tests. Nor are 132 files that would block, exempt until a renderer answers geometry: each fails only because Crane has no renderer to answer geometry (a layout box’s size or position). Per-subtest detail comes from the runner’s result streams: 13,141 of 13,141 files have it in this generation.
