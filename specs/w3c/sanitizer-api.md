## 1. Note

The Sanitizer API has been moved to [WHATWG
HTML](https://html.spec.whatwg.org/#html-sanitization).

### 1.1. Issue Reporting

- [File specification issues in the WHATWG HTML issue
 tracker](https://github.com/whatwg/html/issues).
- Please report bugs in implementations to the corresponding browser
 vendor. We encourage you to look into their security reporting
 policies.
