Angular in Crane

Angular 21.2.11 — TodoMVC; Crane's port of the app spec; the project's own suite is not runnable without Node (QUnit 2.24.2, 1 page). The matrix.

Not run: rendering. Crane draws nothing: tests whose result depends on layout geometry or pixels are not run, and each is listed with its reason. Computed style, events, timers and animations are run. Tests that need a project's Node tooling or its own test server are not run either, and are listed with theirs.

Angular's browser suites are TypeScript bundled by Bazel and esbuild and run by Karma or web-test-runner, all Node. Crane's port runs every test of TodoMVC's app spec (cypress/e2e/spec.cy.js, 29 tests) on the framework's unmodified, prebuilt TodoMVC app, driving it through DOM events as Cypress drives it. Of Cypress's own checks it does not run the parts that need layout: visibility is decided by computed style (no box, visibility, opacity) and not by size, clipping or transforms, and an action does not scroll the element into view or check that nothing covers it. Tests the spec itself skips for an app (its localStorage test for apps that keep no data there, the app's entries in tests/knownIssues.js) are reported as skipped by the app spec. The port: tests/frameworks/todomvc/ in Crane; the spec: cypress/e2e/spec.cy.js.
