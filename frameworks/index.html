3What is not run, and why

rendering 178 tests · following a ruling 7 tests · skipped by the projects 100 tests · skipped by TodoMVC's spec 45 tests
  • Rendering. Crane draws nothing, so tests whose result depends on layout geometry or pixels are not run. Computed style, events, timers and animations do run. Not run for this reason: 178 tests (Angular 15, htmx 13, jQuery 76, React 9, React 17, Svelte 8, Vue 27, Vue 13), each listed with its reason in the project's exclusion list (tools/fw_matrix/excluded/).
  • Crane follows the browsers or the newer spec. Some tests fail in Crane because Crane does what the browser majority does, or what the newer spec says and a shipping browser does, where the test expects another browser's behaviour. Like rendering tests, they are counted in neither column. The browser majority, by a recorded ruling: 5 tests (Angular 4, React 1). The newer spec, which a shipping browser follows: 2 tests (Angular 2). Each is listed with its evidence in the project's exclusion list (tools/fw_matrix/excluded/).
  • Node. Node runs only the projects' own build steps, test servers and test runners, never inside Crane. jQuery's pages are served by its own test server (jquery-test-runner) with its own dependencies. Angular, htmx, React, Svelte and Vue are run by their own test runners, which drive Crane over the Chrome DevTools Protocol as they drive Chrome: Playwright through Crane's WebDriver server (htmx's web-test-runner, React's suites, Svelte's and Vue's Vitest), Puppeteer by launching Crane's console (Vue's e2e tests, Angular's Bazel web-test-runner). The TodoMVC apps are static files, served as they are.
  • Left out by the projects, and the rest. The projects skip 100 tests (Angular 96, htmx 4) themselves. 9 test files run only through the project's Node test runner, not in a browser page (htmx 9). TodoMVC's app spec skips 45 tests for the apps it names (its localStorage test for apps that keep nothing there, and each app's known issues). Angular's web test targets of the documentation site and Angular DevTools (18 and 50 targets): They test two applications kept in the repository (adev/, the angular.dev site, and devtools/, the browser extension), not the framework; the framework's own 44 targets under packages/ run above.

Crane runs TodoMVC's app spec (cypress/e2e/spec.cy.js, 29 tests) through Crane's port of it: the same tests, steps and checks in the app's own page, driving the unmodified app through DOM events as Cypress drives it, with Cypress's configuration read from the project's cypress.config.js (includeShadowDom: queries reach into shadow roots as Cypress's do). What the port cannot do in Crane is layout: an element counts as visible by its computed style (no box, visibility, opacity) and not by its size, clipping or transforms, and an action neither scrolls the element into view nor checks that something covers it. Cypress's hooks that run before an app's own scripts have no in-page equivalent: an app counts as started when its page has loaded and its heading is visible, and the spec's spy on localStorage.setItem is installed then.
