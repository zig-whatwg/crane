# Architecture: A handed-over value is the callee's on every path, its throws included

**Date**: 2026-10-19
**Lesson**: When the binding hands an impl a value to take - a callback-function argument, a callback member of an options dictionary, a thrown value `engine.completionOf` returns OWNED - the impl owns it from the first line of the call. An early `return error.X` before the line that takes it keeps it forever; a caller that frees it again after the callee failed frees it twice.

**Why**: Ownership written as "the record takes it" (`record.handlers.append(engine.takeCallbackFunction(h))`) reads as correct on the success path, which is the only path a reader follows. The checks before it - "perform shared checks", "if the dispatch flag is unset, throw" - are spec steps that come first, so the take lands after every throw. The same shape the other way round: notifyMutationObservers freed the records it handed to `invokeCallback` whenever the call failed, although the callee had taken them (wrapped, they were the wrapper cache's) - so the free was a second one.

**What Happened**: navigation-api/ kept 16 Globals under `leaks --atExit` (lane leaks5's follow-up). Lane leaks6 measured each family with V8's live global-handle count in a Browser test (tests/html/leaks6_navigation_api_handles_test.zig, 64 calls each): `navigate()`/`reload()` with an unserializable state left 4,096 B (the early error result never released the thrown value it was given OWNED), a throwing `NavigationPrecommitController.addHandler()` 2,048 B and a throwing `NavigateEvent.intercept({ handler })` 2,048 B (both took their callbacks only after the checks). And `new MutationObserver(frame's function)` whose frame was removed before the notify microtask made the callback invocation fail with OperationFailed (a Window realm that is not fully active runs nothing) after the records were wrapped; the catch freed them under the wrapper cache.

**Fix**: Take first, then check: `const callback = engine.takeCallbackFunction(handler); errdefer callback.release();` at the top of the hook, and a `handed_over` flag with `defer if (!handed_over) release(...)` in an impl whose throws come before the hook. Release an OWNED thrown value with `defer reason.release()` where it is passed on. In a caller, never free what the callee's contract says it takes - the callee frees on its own failure, and only what it has not given away (`engine.hasWrapper` tells a wrapped record from one still the caller's).

**Takeaway**: **Ownership transfers at the call, not at the line that stores the value. Take a handed-over value before the first check that can throw, and never clean up after a callee that took it.**
