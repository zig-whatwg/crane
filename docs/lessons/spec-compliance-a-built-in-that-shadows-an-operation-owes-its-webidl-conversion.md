# Spec Compliance: A built-in that shadows an operation owes its WebIDL conversion

**Date**: 2026-10-05
**Lesson**: A worker's setTimeout and setInterval are host built-ins defined on the global (worker_host `defineBuiltinFunction`), shadowing the bound WindowOrWorkerGlobalScope operations. A built-in gets raw values, so the WebIDL conversion the binding would have done - the TimerHandler union, the `long` timeout, the `any...` rest - was the built-in's job, and it did only the part one test needed.

**Why**: The built-in accepted a callable and nothing else (`isCallable` or return 0), read the timeout only when it was already a Number and clamped it to 2^31-1, and passed no arguments to the handler. Each shortcut is a WebIDL step skipped: the union converts a non-callable by ToString at the call (and a TrustedScript first), a `long` is ToNumber then modulo 2^32 (so 2^32 is 0 and `"100"` is 100), and `any...` is passed through. HTML's timer initialization steps then work on the converted values: Trusted Types' step 1 for a string, step 10.8's classic script when it fires.

**What Happened**: 12 WPT files timed out on `setTimeout("code")` in a worker - workers/WorkerGlobalScope_setTimeout.htm and _setInterval.htm, the four onerror/message-{classic,module}-* files (their setTimeout-string case), evil-spec-example.any.js's worker half, and the Dedicated/SharedWorker trusted-types timer files. The window's timers had none of these gaps: the V8 adapter's page_realm does the conversion for them (ToString at the call, ToInt32, the rest arguments) before the host's initializeTimer.

**Fix**: worker_host `setTimer` converts as WebIDL does, in the union algorithm's order (a TrustedScript platform object, then a callable, else ToString), the timeout by ToNumber and `convertToLong`, and keeps the arguments; then runs timer initialization step 1 (get trusted type compliant string, sink "WorkerGlobalScope setTimeout"), the CSP check at the call (the stated deviation the window's timers make), and at firing step 10.8 (runClassicScript with the host's reporter). 11 of the 12 files went TIMEOUT -> OK with every subtest passing; the twelfth is the Window's (Trusted Types step 1 is not run for a Window string handler yet).

**Takeaway**: **A host built-in that stands in for an IDL operation receives what the binding would have converted. Write out the operation's whole WebIDL conversion - union member order, integer types' modulo, optional defaults, rest arguments - before its spec steps, and test the conversions (a toString that runs script, a valueOf, 2^32) as well as the happy path.**
