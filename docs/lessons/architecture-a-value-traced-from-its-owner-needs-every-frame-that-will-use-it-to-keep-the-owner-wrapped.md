# Architecture: A value traced from its owner needs every frame that will use it to keep the owner WRAPPED, not just alive

**Date**: 2026-11-19
**Lesson**: When a value moves from a strong root to an edge from its owner's wrapper (refcount step 8: listeners traced from their target), a native frame that holds the owner by count only - an event dispatch's path - no longer keeps the value: a collection under the frame takes the owner's wrapper, and the value with it.

**Why**: A counted reference keeps the native object; a value traced from the owner lives exactly as long as the owner's WRAPPER (WebKit's JSEventListener holds its function as `JSC::Weak` marked from the target's wrapper; Blink traces it from the target). Crane's DispatchPath held its nodes by count (refcount 5g), which was enough while each listener's callback was a strong root of its own. Once the callback is an edge, the dispatch must keep the path's wrappers too, as Chrome does by tracing its EventPath (NodeEventContext `Member<Node>`) and Gecko by holding its chain's targets with strong listeners.

**What Happened**: Lane rc8 made listeners traced values. In 175 html tests, one went red: tests/html/lk1_dispatch_path_holds_test "a native dispatch walks the rest of its path after a microtask of an ancestor's listener took that rest out of the document, collected and made nodes". The body's capturing listener queued a microtask. The microtask removed the rest of the path from the document, dropped script's last reference and collected. The section, article and details wrappers died, and their listeners died with them. The walk still held every node by count and called nothing.

**Fix**: A stack root. `runtime.gc.StackRoot` is an intrusive list on the agent's DeferredTeardown. The dispatcher's frame pushes one (`dom.event_dispatch.ActiveDispatch`) for the dispatch's length. The V8 keep walk (node_wrappers.traceKeeps, every full collection's atomic pause) calls its trace, which walks the path's held nodes with dom.wrapper_tracing.traceHeld. The walk reaches the queue through the isolate's data slot, as a binding entry does: no lock in the pause and no cast of the agent's host pointer. tests/v8/cb8_stack_roots_test.zig pins that while another thread holds the agents' lock. A dispatch pays one push and one pop; a collection pays a walk only while dispatches are in flight.

**Takeaway**: **Before turning a root into an edge from an owner's wrapper, list every native frame that will read the value later, and give each a way to keep the owner's wrapper (a stack root the collector walks), not only a counted reference to the owner.**
