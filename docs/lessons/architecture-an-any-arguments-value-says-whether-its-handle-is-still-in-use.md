# Architecture: An `any` argument's value says whether its handle is still in use

**Date**: 2026-09-30
**Lesson**: `argHandleIsCopied(runtime.JSValue)` answered "kept" for every `any` argument, because a JSValue CAN be a `.handle` over the argument's own Global. Most are not: a string, a number, a boolean, null and undefined convert to Zig values that refer to nothing. The type could not tell the two apart; the converted value can.

**Why**: The predicate is an allowlist over types, and it has to be - two use-after-frees shipped from a guessed "copied". But for an `any`, ownership is decided per call, by the conversion's result: `conv.fromV8Value`'s JSValue branch returns `.handle` over the very handle it was given only for an object, function or symbol. A type-level "no" for JSValue therefore leaked every primitive `any` argument's Global for the process's life - testharness's `abortController.abort("Test cleanup")`, once per subtest, 1,000 a page on big5-decode.

**What Happened**: The same shape was hiding in three other places. `fromV8Sequence` released neither the index key it made per element nor the element's handle, even for `sequence<DOMString>` (two Globals per element of every sequence argument). A dictionary's `any` member kept its Get handle when absent or primitive. And a single-parameter constructor whose parameter type is a union - `DOMString` is a `union(enum)` of its storage - was taken for an overloaded constructor's `ConstructorArgs`: the resolver built `new BroadcastChannel(name)`'s name as an "interned" DOMString that nothing frees (65 leaked allocations over one Crane test).

**Fix**: `anyHandleIsKeptOnlyAsHandle(T)` (an allowlist of `JSValue`, `?JSValue` and their `webidl.Opt` forms) plus `anyConversionKeepsHandle(T, value)`: the binding releases the handle at conversion when the value refers to nothing, in `convertArgReleasing`, the dictionary member loop and the sequence loop. Then, after reading all 422 impl parameters typed `any` (three kept the argument without a hold, and now take one), the binding releases an operation's or constructor's `.handle` argument once the call returns (`releaseAnyArgument`) - the protocol's "a JSValue parameter is borrowed for the call" made true. Only a generated `ConstructorArgs` goes through the overload resolver.

**Takeaway**: **When a type-level ownership predicate must say "kept" for safety, look for a value-level proof before accepting the leak: the conversion's result often says exactly what the type cannot. And before flipping a borrowed-argument rule, read every keeper - the audit is the proof.**
