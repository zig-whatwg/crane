### Architecture
- [A helper move must follow the production module graph](architecture-a-helper-move-must-follow-the-production-module-graph.md) - Check the destination module's actual dependency table; a matching import elsewhere does not make a move compile.
- [A tree version does not cover custom-element upgrades](architecture-a-tree-version-does-not-cover-custom-element-upgrades.md) - Cache validity follows every input to the answer, including classification changes that do not mutate the tree.
- [A free is not a mutation - a version script can observe must not move with the collector](architecture-a-free-is-not-a-mutation.md) - A counter that script can observe through an API counts only what the spec calls a mutation - not a free, not a creation; never let the collector move it. A cache that needs to hear about frees proves from ownership that nothing it remembers is freed, and checks each entry cheaply.
- [A live list needs a native owner for its backing object](architecture-a-live-list-needs-a-native-owner-for-its-backing-object.md) - An engine edge and a generation check do not replace a native owner for a non-node backing object.
- [An IDL string getter copies; a tree read borrows](architecture-an-idl-string-getter-copies-a-tree-read-borrows.md) - Before moving a call onto the generated interface, read the generated member and the impl member side by side: a link getter forwards, a string getter copies, a setter runs the IDL algorithm.
- [A union result is owned as its active member is](architecture-a-union-result-is-owned-as-its-active-member.md) - An ownership rule keyed on a type is wrong for a union: ask the value which member it holds, and keep the safe default for every member you cannot prove fresh.
- [A curl multi handle is its agent's; the connections are its Browser's](architecture-a-multi-handle-is-the-agent-s-the-connections-are-the-browser-s.md) - Choose a network object's owner by its thread rule: single-threaded handles go to the agent that pumps them; shared, locked state goes to the Browser - never to a thread, and never to the process.
- [Free a parser buffer on one cleanup path](architecture-free-a-parser-buffer-on-one-cleanup-path.md) - Use one deferred cleanup for temporary storage, and test failure at the final allocation as well as success.
- [Find an object's Browser from its address, not from its context](architecture-find-an-objects-browser-from-its-address-not-its-context.md) - An owner you can only reach through a context dies with the context; put the owner where the object's memory is - an allocation block aligned to its size names its allocator for free.
- [A traced edge keeps an object from the collector, not from its realm's end](architecture-a-traced-edge-keeps-an-object-from-the-collector-not-from-its-realm-s-end.md) - A traced edge is a reason for the collector to keep an object, not a guarantee that it lives: if the object can come from another realm, its realm's end frees it - read it through a generation check everywhere, and find out by ending that realm in a test.
- [A flag made counted changes every caller - audit them all, and test each by collection](architecture-a-flag-made-counted-changes-every-caller.md) - Changing a primitive's counting semantics is a change to every caller: grep them all (no `head`), balance each with its own bool, and prove each one by collecting the object it keeps.
- [A threadlocal listener list splits a Browser when its work moves threads](architecture-a-threadlocal-listener-list-splits-a-browser-when-its-work-moves-threads.md) - When work moves to another thread, every threadlocal registry it reached becomes one partition per thread, and nothing says so: give each its real owner (Browser, agent, realm) and deliver across threads through the owner's task sink.
- [An identity edge drawn at hold time is no memory net while the collector frees trees](architecture-an-identity-edge-drawn-at-hold-time-is-no-memory-net.md) - An edge drawn when a hold begins cannot follow wrappers made later: until counts decide lifetimes, wrap the held tree's root when the hold begins.
- [A dying tree's holds stay on its root - unlink for teardown without moving counts](architecture-a-dying-tree-s-holds-stay-on-its-root.md) - In a dying tree, the root owns the books: unlink children without moving counts, and settle the whole total once, at the root's free.
- [A back-link script can read must keep what it names - draw the edge where the wrapper is made, and redraw it where the link moves](architecture-a-back-link-script-can-read-must-keep-what-it-names.md) - A pointer script can read back is a reference, not a cache: give it an edge from its holder's wrapper, drawn where the wrapper is made, and route every write through one setter that redraws it - or the first collection turns it into a use-after-free.
- [V8's RegExp::Exec is RegExpExec, not the built-in exec](architecture-v8-regexp-exec-is-regexpexec-not-the-builtin.md) - A V8 API named after a built-in may still do the spec's observable lookups; read api.cc for what it calls, and run built-in-only steps in a context no script can reach - one per agent, not one per call.
- [Holds on nodes are a chain on the node - a removal asks exactly the holders that hold something in it](architecture-node-holds-are-a-chain-on-the-node.md) - Mark a held node with the head of its holders' chain, not a bit: a removal of nothing held stays a field test, and a removal of something held asks exactly its holders - pay one wrapper for the detached root, never one per node.
- [A collected tree is freed between tasks, a slice at a time](architecture-a-collected-tree-is-freed-between-tasks-a-slice-at-a-time.md) - A teardown's cost lands where it runs: put a collected tree's teardown on the event loop, between tasks and in slices, and re-check ownership when it runs.
- [Under kAuto, every do_callback=true API at call depth 0 is a microtask checkpoint](architecture-under-kauto-every-do-callback-api-at-depth-zero-is-a-checkpoint.md) - Under kAuto, a native step is a microtask checkpoint unless it proves otherwise: read the API's ENTER_V8 macro in api.cc for the version you link, and measure the call-completed callback rather than guessing which calls fire.
