# Workflow: Final replay does not prove intermediate builds

**Date**: 2026-10-29
**Lesson**: A byte-identical final patch replay can still hide a dependency missing from an earlier feature commit.

**Why**: Replay validates patch preimages and the final tree; it does not compile each cumulative feature boundary.

**What Happened**: CSSOM counter-style rules set numeric bound metadata that the reordered Typed OM map package introduced later. All fifteen packages replayed to the approved 125-file composite, but the counter-only runner failed because Grammar lacked minimum_kind. Earlier diagnostics had exercised the complete tree and therefore included that dependency.

**Fix**: Preserve the failed gate. Audit the exact missing declaration and obtain the liaison's hunk-order ruling. Move only the seven-line metadata prerequisite into the counter feature, re-anchor the later package, and prove every final image unchanged. Gate and focus the corrected cumulative feature before committing it.

**Takeaway**: **Verify dependencies at each independently committed feature boundary; final-tree identity does not prove that boundary builds.**
