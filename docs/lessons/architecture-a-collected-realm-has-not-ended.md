# Architecture: A collected realm has not ended - what it names must live until its end

**Date**: 2026-11-15
**Lesson**: Between the moment the collector takes a detached realm and the task that ends that realm, the realm's Window and tree are still allocated. Anything the collector frees in that window that the Window still names by a plain pointer is a use-after-free for native code that reaches the realm.

**Why**: A realm's end runs page teardown, so the collector's weak callback only marks the realm (no engine behind it) and queues the end as a task (protocol_realms.realmCollected). The same collection takes the wrappers of the realm's platform objects, and their finalizers ran at the agent's next safe point - before the queued task. So for one or more event loop turns the Window outlived objects it made and names without a count: its Performance, its Navigator, its Storage objects. Each was kept alive only by a traced edge from the global object, which is gone. Script cannot reach such a realm; a native weak reference of the (address, slab generation) kind can, because the tree's slots have not been freed.

**What Happened**: The WPT runner's pointer fired boundary events at a button of a collected realm; the event's timestamp step read the freed Performance object (a segmentation fault in 3 of 96 bug-finding runner processes; 39 of 96 leaked the events instead, because Instance.releaseIfUnwrapped left every object of a realm with no engine).

**Fix**: Two rules, both in lane tl1's state unit. (1) A collected realm's objects are torn down by the realm's end, never ahead of it: wrapper_cache.zig finalizeCollected leaves an entry collected and pending while `WrapperCache.realm_collected` is set, and the cache's end frees it after the Window, in the order it uses for a realm that ends without having been collected. Blink has no such window: a window's Performance is traced from the window (LocalDOMWindow::Trace -> its supplements -> GlobalPerformanceImpl::Trace), so both go in one collection. (2) An object made in a realm whose engine has gone, and never wrapped, is freed by whoever made it: `ContextData.engine_gone` tells a collected or ended realm from a unit test's context made with no engine, and releaseIfUnwrapped frees a never-wrapped non-node object of such a realm. The test of the state needs no pointer: tests/html/tl1_collected_realm_window_test.zig.

**Takeaway**: **When an object's end is deferred to a task, everything it names by plain pointer lives until that task. "Nothing of script reaches it" is not "nothing reaches it": every weak reference by address and generation can still arrive, so a reader checks `fullyActive` (or the realm's engine) before it acts on what the reference returns.**
