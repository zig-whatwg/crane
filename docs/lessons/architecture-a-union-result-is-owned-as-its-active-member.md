# Architecture: A union result is owned as its active member is

**Date**: 2026-10-11
**Status (2026-11-23, lane bind1 batch B, B2)**: the rule stands, and its safe default has a price worth checking whenever results are retyped. When every union became a typed union in every position, results that had been a `runtime.JSValue` (whose `.undefined` arm was already released) became `(Event or undefined)` and `(CustomElementConstructor or undefined)`: codegen gives an `undefined` member a `void` field, `memberValueIsOwned` had no answer for `void`, and "kept" left the Undefined `toV8Value` makes for it - one Global per `window.event` read outside a dispatch and per `customElements.get()` of an undefined name (`leaks --atExit` over 163 files: 19 leaks, all `malloc in v8_Undefined`; 11 generated unions have the member). `void` now answers "made for the call" (tests/v8/union_return_ownership_test.zig). When a retyping changes which types reach an ownership predicate, list the member kinds the new types have against the predicate's allowlist, and run `leaks --atExit` before the sweep, not after it.
**Lesson**: Whether the handle a result converts to is the binding's to release depends on the converted value, so for a union it is decided by the active member at run time, never by the union type at comptime.
**Status** (2026-11-23, lane bind1 batch B, B2): every union is typed in every position now, so a RETURNED union's member is owned by the rule its type follows returned on its own (`conversions.unionReturnIsOwned`), not by `unionValueIsOwned`'s rule for a value put into an object: a runtime.JSValue member is the binding's, as a JSValue result is (engine.Owned: "the binding releases what an impl returns"), an instance's wrapper the cache's, a callback function member borrowed (an EventHandler getter's rule); an owned DOMString member is freed once its String is made (`freeReturnedUnion` - finishGetter and finishOperation freed no union's strings). ImageData.data, the one impl that returned a kept handle in a union, now hands over a hold of its own (tests/v8/union_return_ownership_test.zig).

**Why**: `convertReturnValue` (interface.zig) sets `owned` per type: a string, number, boolean or enum result is a Global made for the call and released once set; a platform object is its wrapper, the wrapper cache's. A union is neither - FormDataEntryValue is (File or USVString) - and the branch for unions left `owned` false for all of them, the conservative answer for the File arm, a leak for the string arm.

**What Happened**: Every `FormData.get()` that returned a string kept its String Global: 32 B of V8 global handles per call (2048 B over tests/v8/per_call_handle_test.zig's 64 calls), found by Codex row 19 (Q13). Lane callleak's per-call fixes had covered each type family but not a union that mixes them.

**Fix**: `conversions.unionValueIsOwned(T, value)` switches on the active member and applies the rule a dictionary member's value follows (`dictionaryMemberValueIsOwned`: strings, numbers, booleans, enums, dictionaries, sequences - fresh), a nested union by its own active member; an interface, `any`, `object` or `*anyopaque` member stays kept. The default is KEPT, pinned in tests/v8/retention_predicate_test.zig. Attribute getters returning unions (CSSNumberish, VTTCue.line, AnimationPlaybackEvent.currentTime) go through PropertyGetterCallback's comptime `getterValueIsOwned`, which answers false for every union: the same leak, left for that path's owner.

**Takeaway**: **An ownership rule keyed on a type is wrong for a union: ask the value which member it holds, and keep the safe default for every member you cannot prove fresh.**
