# Testing: A TSAN suppression anchored at a namespace misses template frames, and a gate is proven only by races it must still report

**Date**: 2026-11-11
**Lesson**: ThreadSanitizer matches a `race:` pattern against the symbolized function name of every frame in a report, and a symbolized template function starts with its RETURN TYPE: `void v8::internal::Utf8DecoderBase<...>::Decode<unsigned char>`, `unsigned long std::__Cr::__hash_table<...>::__erase_unique<...>`, `heap::base::SlotCallbackResult v8::internal::Scavenger::ScavengeObject<...>`. A pattern anchored at the namespace (`race:^v8::`) misses all of them. And a suppression set is proven only by races it must still report, planted in the same binary: one per class the suppressions could hide.

**Why**: TSAN's suppression templates support `^` and `$`, and the name it matches is the demangled symbol with its signature. V8 15.7's absl::Mutex is invisible to TSAN, so V8-internal handoffs show up as races, and the only frame of V8 in such a report is the interceptor's caller, which is very often a template.

**What Happened**: Lane v8up b3f replaced b3e's `ignore_interceptors_accesses=1` (too wide: it drops a Zig free or memcpy racing a Zig read) with V8-namespace suppressions. The snapshot generator went from 317 reports to 1 to 0 with `^v8:: ^absl:: ^cppgc:: ^heap::base:: ^std::__Cr::`, but the verify run of tests-v8 and tests-html still failed in 6 + 5 tests on V8-only reports whose frames started with `void ` or `unsigned long `. Unanchored, the patterns cannot reach Zig code, because each holds "::" and Zig symbols are dotted (`heap.c_allocator_impl.free`). The first "free" race planted to prove the gate was reported through Zig's own `@memset` in Allocator.free, which would have been reported with the wide option too - it proved nothing about the interceptors until it was rewritten to call `std.c.free` directly.

**Fix**: tools/test_launcher/tsan_suppressions.txt section 5: `race:v8::`, `race:absl::`, `race:cppgc::`, `race:heap::base::`, `race:std::__Cr::`, unanchored, with the "::" argument written above them. The proof plants three races in a -Dsanitize-thread verify of tests-v8 (lane v8up's .v8up/job-b3f-tsan.sh BITE=1): a Zig write racing a Zig write; libc's free called from Zig racing a Zig read (the interceptor is that side's only access); a Zig write inside a native callback JS called (V8 on the native stack) racing a Zig write. All three are reported; every other test passes.

**Takeaway**: **Read the symbolized names a suppression must match before anchoring it, and prove a suppression set with a planted race for each class it could hide - each one built so that only the gate you are keeping can report it.**
